# Hackathon_Week_3

Childhood heart tracker----

I want to start with why i went with this project, a healthcare project. Few months ago my father had a heart surgery due to a damaged valve. Upon many tests, they found out it was since childhood he had this issue. Many symptoms over the year were missed. Had those symptoms were recognized earlier, illness would have been treated sooner and recovery would be much easier. Hence I build a tracker based on symptoms, data from Mayo, CDC and WHO were used.
I want to emphasize that certain data was simulated like symptoms, daily child data. It is based on random data that has been simulated. 

** How the project works**

First I calculated the murmur rate, BMI to check relation between murmur rate and a child's BMI, weight and activity rate.
